# Porch Light

Original instrumental written for Backyard Smokeout in November 2026.

- File: `porch-light.ogg` (and `porch-light.wav`, the same take)
- How it was made: `compose_porch_light.py` writes every sample. There is no recording, sample pack, MIDI import, or reference track.
- What it is not: not a cover, not a hit song, not a meme audio, and not a Roblox library sound.
- Feel: 96 BPM, G major, 40 seconds, 16 bars. A quiet whistle, a soft bass, and a light shaker. It fades to silence at the join so a loop does not click.
- Rights: this file was composed for this game. The place owner can upload it to Roblox as their own audio. Nobody else needs to be credited, and nothing in it is licensed from a publisher.

The game does not play this file until the owner uploads it and sets `id` in `src/shared/Music.luau`. While that id is `0`, the client stays silent on purpose.
